# Family House Connect Mobile

Unified Flutter implementation of the approved Church, Mission, KCA, Press, and shared-service mobile designs.

Run the canonical visual target:

```sh
flutter run -d chrome --web-port 7357
```

Open a canonical route directly, for example `/home`, `/church`, `/mission`, `/kca`, `/press`, `/events`, `/giving`, `/notifications`, `/profile`, or `/settings`. Every screen is also addressable by ID through `/screen/<ID>`.

See `REQUIREMENTS_TRACEABILITY.md` for role, permission, API-domain, reference, and verification status.
